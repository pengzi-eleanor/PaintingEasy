# CreatingEasy 开发路线图

## 阶段 1：MVP（当前）

- 完成 Manifest V3 插件、四个主要 Tab 与约 380px Popup。
- 使用本地 mock 数据演示关键词选择、图库跳转、识图标签和会话历史。
- 建立 FastAPI 健康检查、文本优化与图片分析的稳定 Pydantic 契约。

## 阶段 2：可靠的关键词能力

- 引入可替换的词库/规则提供器，覆盖纠错、翻译、去重和基础扩展。
- 插件接入版本化后端 API，完善加载、超时、部分失败与重试状态。
- 将设置和有限历史保存到 Chrome Storage，并提供清除能力。

## 阶段 3：图片语义与描述转关键词

- 通过供应商协议接入 Qwen2.5-VL、Gemini 或兼容服务，密钥仅从服务端环境读取。
- 对上传文件做真实内容验证、大小限制、随机临时命名与可靠清理。
- 明确标记模型建议，允许编辑、拒绝、回退和供应商降级。

## 阶段 4：语义扩展与以图搜图

- 使用 Embedding 对候选词扩展和可解释排序。
- 使用 OpenCLIP 生成视觉向量、FAISS 执行近邻检索。
- 区分文本相关性、视觉相似度、质量和来源权重，并分别展示依据。

## 阶段 5：图库连接器与生产化

- 在后端实现可替换的图库连接器、统一领域模型、规范化和跨源去重。
- 增加超时、有限重试、并发上限、限流处理和部分成功响应。
- 完成隐私、安全、许可、署名、可观测性和端到端测试。
