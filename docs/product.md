# CreatingEasy 产品说明

## 项目目标

CreatingEasy 为需要频繁寻找图片、设计参考和创作素材的用户提供统一搜索入口。MVP 不聚合第三方图库结果，而是把自然语言需求转换成可编辑的英文检索词，再将用户带到常用素材平台，减少重复输入和低效试错。

## 核心功能

1. **文本搜索优化**：保留原始查询，给出可单独选择或删除的英文关键词建议，并支持跳转多个图库。
2. **图片识别搜索**：从图片中提取对象、场景、风格、色彩与构图词；当前版本使用 mock 结果。
3. **历史记录**：在当前插件会话中回看文本和图片搜索记录。
4. **设置**：选择默认素材平台，并清楚展示当前数据处理状态。

所有 AI 生成内容均标记为建议，并允许用户编辑、拒绝或回退。当前前端不连接后端，也不会上传用户图片或查询。

## 用户流程

### 文本搜索

1. 用户输入自然语言素材描述。
2. 插件生成一组可选关键词并标记为 mock AI 建议。
3. 用户勾选需要的词，点击素材平台名称打开对应搜索页。
4. 搜索写入会话历史，方便复用。

### 图片搜索

1. 用户选择本地 JPG、PNG 或 WebP 图片。
2. 插件展示 mock 语义标签，用户可逐个删除。
3. 用户用保留的标签跳转到默认素材平台搜索。

未来接入后端后，图片应限制大小、验证真实内容、仅短暂处理并及时清理；API 密钥只保存在服务端环境变量中。
